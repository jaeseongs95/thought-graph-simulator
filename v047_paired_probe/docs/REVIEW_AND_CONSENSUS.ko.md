# 다각도 심사와 합의

## 결론

다음 작업은 모델을 교체하거나 v045 설계로 되돌아가는 것이 아니라, **같은 작은 모델에서 원식·교환식·실제 NOT→AND 연결을 동일 배치에 넣는 통제된 재현 실험**이다. v046 성공 기준선은 수정하지 않고 보존한다.

이번 문서는 사용자 제공 검증보고서와 연결된 GitHub의 v045/v046 구현을 근거로 작성했다. 사용자 제공 보고서의 ZIP 원문을 이번 환경에서 다시 열어 감사한 것은 아니다. 여러 심사 관점의 논증 대조이며 별도 외부 심사위원이나 독립 에이전트를 호출한 결과가 아니다.

## 증거를 먼저 구분한다

사용자가 제공한 검증보고서에 따르면 새 응답 12건이 모두 정확했고, 교환식 4/4와 실제 NOT→AND 파이프라인의 중간값·최종값 4/4가 확인됐다. 원식의 기존 결과는 3/4이며 유일한 양성 조건에서 실패했다. 원문 재생성·독립 파서·진리표·오류 주입·기존 시험을 통한 검증도 보고됐다. 이 결과를 현재 성공 기준선으로 인정한다.

이번에 직접 읽은 `composition_probe.py`는 부모 NOT의 실제 응답을 다음 AND의 b에 넣고, 부모값의 정확성·AND의 국소 정확성·원래 식의 최종 정확성을 따로 검사한다. `operator_probe.py`의 실제 원식은 `(a AND (NOT b))`이고 교환식은 `((NOT b) AND a)`다. 두 식 모두 바깥 괄호가 있으며 보고서에서 생략된 표기와 실제 전송 문자열을 구분했다.

## 토론에서 정리한 쟁점

형식 검증 측의 “현재 PASS는 유효하다”와 인과 추론 측의 “분해의 유일성을 증명하지 않았다”는 서로 반대되는 말이 아니다. 전자는 실행 성공의 진위, 후자는 성공의 설명 범위를 다룬다. 두 판단을 동시에 채택한다.

모델 행동 측은 “복합식을 못 한다”는 설명을 버려야 한다. 교환식도 실패해야 성립하는 설명이기 때문이다. 그렇다고 이번 시도에서 내부 attention, 토큰 위치 처리, 학습 데이터 분포 중 무엇이 실제 원인이었는지 특정할 수 있는 것은 아니다. 다음 실험은 우선 **조작 가능한 입력·실행 조건이 결과를 바꾸는지**를 판별한다.

통계 측은 반복 횟수를 늘리되 목적을 명시해야 한다. 같은 seed와 동일한 프롬프트 반복은 주로 재현 안정성과 실행 순서 영향을 확인한다. 동일한 네 입력을 24개 새로운 논리 문제로 세거나, temperature 0에서 seed 숫자를 바꾼 사실만으로 독립적인 무작위 표본이 생겼다고 계산하지 않는다.

시스템 측은 두 경로를 최종값 기준으로 공평하게 비교하되, 파이프라인에는 추가로 중간값을 포함한 구조적 정확성을 보고하도록 요구한다. 직접식의 내부 중간값을 관측하지 않았으므로 직접식에 “모든 내부 단계가 정확했다”는 점수를 부여하지 않는다.

## 합의문

**v046은 유효한 구성요소 성공 기준선으로 보존한다. 다음은 동일 모델·동일 원문 계약 아래서 세 경로를 대응 비교하는 v047이다. 이 실험에서는 결과를 보기 전에 조건·순서·평가 지표를 고정하고, 실패도 자료로 남긴다. 이후 표현·문제 일반화와 원래 A/D/M 전체 작업의 연결을 확인한 뒤 모델 규모·계산량 비교를 확장한다.**

프로그램 종료 코드나 자료 무결성 PASS를 모델 성능 PASS로 사용하지 않는다. 실험 결과가 예상한 패턴과 다르더라도 완료된 유효한 비교 자료라면 그것이 이번 연구의 결과다.
