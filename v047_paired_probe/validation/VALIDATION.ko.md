# 구현·시험 수행 기록

## 실제로 완료한 작업

연결 GitHub에서 v045/v046의 요청 생성·부모값 전달·판정·직렬화·모델 식별 계약을 읽었다. 이를 바탕으로 기존 `local_llm`을 교체하지 않는 추가 모듈 `paired_probe_v047`을 구현했다. 저장소에는 쓰기 작업을 하지 않았다.

Python 3.13.5 / Linux에서 **75개 단위·통합·CLI 시험을 실제 실행했고 75개 모두 통과**했다. `python -m compileall`도 통과했다. 실제 명령행 프로세스로 `prepare → show → run → audit`를 호출하는 통합 시험이 포함되어 있다. Python 3.10 문법 호환성도 AST 검사로 확인했다. 3.10/3.12 런타임을 직접 실행한 결과와는 구분한다.

별도로 가짜 HTTP 서버에서 기본 계획 전체 **96회 요청**을 실행했다. 의도적으로 원식만 항상 false를 반환하도록 만든 합성 대조에서 원식 18/24, 교환식 24/24, 파이프라인의 중간값 포함 24/24가 기록됐다. 가짜 서버를 종료한 후 원문과 동결 계획만으로 다시 감사하여 같은 결과를 얻었다. 이 수치는 **시험용으로 만든 데이터이며 사용자의 실제 LLM 성공 표본이 아니다.**

## 시험에 포함된 주요 반례

자료형/형식 오류 8개를 거부하는 시험, 부모·최종값의 16개 상태 조합 시험, 네 파이프라인의 8비트에 대한 256조합 시험을 수행했다. 256조합 중 전체 중간값·최종값이 맞는 한 조합만 전체 파이프라인 성공으로 인정했다. 최종값 네 개가 전부 맞지만 중간값이 틀린 15개 조합은 전체 성공으로 인정하지 않았다.

실제 가짜 HTTP 왕복으로 틀린 NOT bool이 보정되지 않고 자식에게 전달되는지 시험했다. 형식상 bool이 없을 때는 자식이 생략되고 실패가 기록되는지, HTTP 오류에 자동 재시도가 없는지, 모델 식별이 달라지면 완료된 비교로 인정하지 않는지도 시험했다.

원문 응답 값 변경, 요청 변경 후 해시 재작성, 부모 해시 변경, event 누락·중복, 결과 폴더의 계획만 재작성, 소스 스냅샷 변경, 합성 자료를 실제 자료로 라벨만 변경하는 경우도 검사했다. 이 시험은 외부 동결 계획과 관측된 파일의 일관성 검사 범위다. 모든 자료를 함께 위조한 악의적 서버나 실행 사실의 외부 증명까지 검증했다고 주장하지 않는다.

같은 seed 반복을 독립 과제의 통계로 처리하지 않는지, 비용에 두 번째 호출이 포함되는지, 모델의 오답을 올바르게 기록한 자료가 무결성 실패로 잘못 분류되지 않는지도 시험했다.

## 아직 실제 실행하지 않은 것

사용자 PC의 실제 Ollama/4B 모델에 대한 v047 추론은 **0회**다. Windows PowerShell 스크립트를 Windows에서 실행하지 않았으며 이 환경에는 `pwsh`가 없다. PowerShell 스크립트는 Windows PowerShell의 한글 읽기를 위해 UTF-8 BOM으로 제공한다. Python 명령의 실제 실행 시험은 위 Linux 환경의 가짜 서버에서 수행했다.

사용자가 붙여준 v046 검증보고서는 분석 근거로 사용했지만 그 검증 ZIP의 원문을 이번 환경에서 다시 열어 재감사하지 않았다. 새 모듈을 실제 사용자 결과 폴더와 서버에 적용하는 확인은 제공된 `prepare`와 `run` 단계에서 수행된다. 기존 28개 오프라인 시험을 새로 실행했다고 표시하지 않는다.

A/D/M 전체 역할 실험, 다른 식/다른 모델의 실험, 동일 FLOPs 비교는 이번 패키지의 구현·실행 범위가 아니다. 다음 연구 단계 문서에 설계 방향으로 구분했다.

## 파일

`selftest.txt`는 시험 로그, `BUILD_STATUS.json`은 기계 판독 수행 기록이다. `demo_pattern`에는 합성 원본, 동결 계획, 96회 HTTP 요청/응답, 재검사 결과가 들어 있다. `reproduce_demo.py`로 별도 새 경로에 같은 종류의 합성 실행을 만들 수 있다.

```powershell
python .\validation\reproduce_demo.py
```

가짜 서버 실행 결과를 오프라인에서만 재검사하는 명령은 다음과 같다.

```powershell
python -m paired_probe_v047 audit --plan .\validation\demo_pattern\frozen.plan.json --run .\validation\demo_pattern\run
```
