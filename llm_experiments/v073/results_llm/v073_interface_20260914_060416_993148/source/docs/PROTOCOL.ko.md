# v073 실험 계약

상세 동결 계획과 분기는 `PLAN_LEDGER.ko.md` P01을 따른다. 기계 판독 계약은 `../data/protocol.json`이며 동결 실행 계획은 source·protocol·v072 baseline의 SHA-256을 포함한다.

## 실행 전 필수 상태

Python 3.10 이상, 실행 중인 로컬 Ollama, v072와 같은 `gemma3:4b` 및 네이티브 설정, 동결된 v072 evidence ZIP이 필요하다. 서버 버전·digest·템플릿·설정이 바뀌면 첫 추론 전에 중단한다. 자동 다운로드·갱신·서버 시작·재시도는 없다.

## 표본과 호출

고유 숫자쌍 4개, seed 2개, 후보 순서 2개로 16개 block. 각 block의 공백 2개 × 요구 2개로 4회, 총 64회다. 32개 전후 metadata action을 합해 96개 action이다. metadata는 추론에 포함하지 않는다. 원응답 generation token 상한은 요청당 4096으로 v072와 동일하다. 이것은 예약·과금 토큰이 아니라 중단 검사 상한이다.

## 완료와 판정

완료는 실행 action의 완결성이고 통과는 측정 기준 충족이다. 두 상태를 혼동하지 않는다. 형식별 선택 32/32 및 방향 쌍 16/16을 요구한다. 전체 gate는 64개 수치 선택이 모두 측정되고 실행이 완료된 경우에만 판정한다. 상세 분기는 장부 P01.5를 따른다.

정상적인 오답은 고치지 않고 다음 예정 호출로 진행한다. JSON/스키마 오류도 raw를 보존하고 새 호출로 해당 요청을 재시도하지 않는다. HTTP·transport·identity·상한 초과는 그 자리에서 배치를 중단한다. length 종료와 미실행은 별도 미측정으로 유지한다.

## 반복 및 오류

자동화와 CLI 모두 같은 results 폴더의 `frozen_batch.started.json`으로 중복 실행을 막는다. 경고를 회피하려고 이 파일을 지우거나 결과 폴더를 바꾸지 않는다. 사용자가 파일을 수동 복사해 별도 디렉터리에서 실행하는 행위까지 막는 전역 인증 장치는 아니다.

중단된 결과의 오프라인 증거 내보내기는 가능하다. 이미 export한 파일을 덮어쓰지 않는다. 수동 복구가 필요할 때는 보존 파일을 먼저 검토한다. 실행기에서 다음 실험 또는 다른 모델로 이동하지 않는다.

## 독립 검산의 범위

독립 검산기는 생산 계획 생성기·실행기·보고서 모듈을 import하지 않는다. 요청/순서 재구성, 모델 identity, 이벤트 체인, 원응답 채점, 집계, 한국어 보고서 재현을 별도로 계산한다. 공유 바이트/JSON/ZIP 도구와 동결 프로토콜, 해시 고정 직전 검산 래퍼는 사용한다. 이는 다른 연구자가 작성한 구현이라는 뜻은 아니며 검산 일치가 설계의 인과적 타당성을 자동 증명하지 않는다.
