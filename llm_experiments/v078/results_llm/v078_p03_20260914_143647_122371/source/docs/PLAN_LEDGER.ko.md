## 사전 해석

- 동일 규칙 수 조건은 규칙 수만으로 두 후보를 구별할 수 없는 조건이다. 후보 위치·동률 처리·우연 성공은 순서 교차별 결과와 함께 판독하며 일부 pair 성공만으로 모든 대체 설명을 배제하지 않는다.
- 역전 조건에서 선택과 실제 종단이 모두 성공하면 단순한 “규칙 수가 크면 deep” 규칙으로는 그 성공을 설명할 수 없다.
- 선택 성공/생성 실패라면 해당 조건의 경로 선택은 보존하고 전체 증명 생성 병목을 기록한다. 선택 실패/정확 생성이면 잘못된 선택을 생성기가 충실히 따랐다고 분리한다.
- 한 문제·seed 일부 성공을 일반 문제 해결 능력·내부 사고 제어·A/M·큰 모델 동등성·비용 우월성으로 확장하지 않는다.
- 새 구조4개와 반복32조건을 구분한다. 수작업 새 확인 세트이며 외부 독립 표집/블라인드 holdout이라고 부르지 않는다.
