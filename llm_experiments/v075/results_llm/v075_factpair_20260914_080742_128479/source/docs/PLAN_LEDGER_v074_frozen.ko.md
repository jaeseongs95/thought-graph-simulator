## P02의 이번 재정의

사용자의 v073 결론에 따른 소스 작성 요청을 근거로 원래 경로 선택→생성 프로토콜을 새로 작성했다. 기존에 승인되었던 v073 검사에 호출을 덧붙이는 것이 아니다.

선택기·생성기는 모두 v069 구성 이력이 있는 Qwen을 사용한다. 두 후보를 규칙 ID 목록만으로 보여 주는 대신 **해당 후보의 원래 규칙 본문 묶음**으로 제공한다. 모델은 후보 ID 하나를 출력한다. 호스트는 고정 표에 대응시킬 뿐 정답 D로 선택을 바꾸지 않는다. 실제 선택 원문과 실제 생성 원문은 그대로 다음 호출에 전달한다.

같은 문제·seed·후보 순서에서 작은 D/큰 D를 모두 시험한다. 생성 입력에서는 원래 D 요구를 숨기고 선택된 경로만 따른다. 별도 참조 구성 12건은 실험자가 경로를 지정하므로 모델 자율 선택 성공에 합산하지 않는다. 이 대조와 실제 모델 원문은 표현/provenance가 다를 수 있으므로 대조 차이를 선택 정확성만의 인과 효과로 해석하지 않는다.

주지표는 모델 선택을 포함한 **유효한 최종 graph와 실제 D의 양방향 변화**다. 별도로 선택, 단계 계약, 최종 구조, 경로 충실성, 참조 구성을 기록한다. 정확한 숫자 보고 과제는 없다.
