# v069 분석에서 v070으로의 결정

v069 원응답 54개, 조합된 전체 증명 12개, 증명 노드 58개를 확인했다. 실제 사용자 evidence의 strict/stage/reference/D 판정은 모두 성공이었다. E01 긴 경로는 규칙 3개지만 병렬 가지가 합쳐져 D=2이며 E02 긴 경로는 D=4다. v068에서 틀렸던 부모 연결과 final ID를 호스트가 교정한 결과가 아니라 새 v069 모델 원응답의 성공이다.

생산 계산 재실행, 고정 독립 검산기 재실행, 별도 raw graph 재계산에서 차이가 없었다. actual model inference 기록과 합성 HTTP/단위시험은 구분한다. 과거 independent PASS 자체를 추가 독립 실험으로 세지 않는다.

현재 해석: **지정 경로와 단계별 규칙을 공급하는 이 계약에서는 이미 본 12조건에 대한 완전 증명 구성 기준선이 확보됐다.** D만으로 경로를 선택하는 기준선은 별개다. v068과 동시 무작위 대조가 아니므로 성공 차이 8→12를 append-only 단일 요인의 인과효과라고 판정하지 않는다.

대안 비교: 같은 구성 문구를 또 바꿀 이유는 없다. 즉시 전체 selector→generator 연결을 크게 실행하면 새로운 선택 오류와 연결 분포 변화를 다시 섞고 호출 수가 늘어난다. 먼저 후보 선택 출력을 제한된 40회로 검증한 뒤, 성공 시 연결을 별도 검증하는 것으로 정했다. 기존 구성기를 새 선택기의 성공률로 대체하거나 연결 성공을 가정하지 않는다.

v070의 두 추가 대조는 모델 내부를 설명하기 위한 것이 아니라, 현재 세 문제에서 규칙 개수와 D가 함께 움직이는 설계상의 겹침을 제거하기 위한 것이다. 목록 길이에만 반응하는 가상 선택기는 C01/C02를 통과하지 못해야 한다. 생성 과정에서 사전 기대 D를 실제 출력으로 채우지 않는다.

배포 자동화에 같은 버전의 새 RunName 재시작 방지 표지를 추가했다. 이전 버전 소스/증거는 보존한다. 새 라이브 실험은 개발 환경에서 실행하지 않는다.
