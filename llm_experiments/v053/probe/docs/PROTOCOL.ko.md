# v053 실험 계약

## 질문

동일한 문제·목표에서 원래의 최소/최대 깊이 지시와 재귀적 깊이 정의를 명시한 지시를 비교할 때, 모델이 실제 증명 경로의 깊이를 선택적으로 바꾸는가?

현재 v052 관측은 K01에서 항상 깊이 2, T02에서 항상 깊이 1이다. 두 문제에서 선택한 경로가 각각 규칙 목록상 먼저 탐색할 수 있는 가지와 일치한다. 이는 순서 영향의 후보 근거지만 순서를 바꾸어 측정한 결과는 아니다. v053은 순서를 고정하고 **정의 명시 효과 한 가지**를 먼저 검사한다. 정의 명시만으로 모든 원인 후보를 구분했다고 주장하지 않는다.

## 고정 조건과 개입

K01/T02의 사실·규칙 순서·목표, 10개 전체 seed, 모델 digest/show/server identity, endpoint, think 여부와 모든 샘플링·실행 옵션을 v052 외부 계획에서 보존한다. schema는 모든 조건에 동일한 GRAPH다. 반환 형식으로 D 정답을 강제하지 않는다. 원래의 경로 선택 문장은 그대로다.

- original: v052 D 단독의 요청 바이트를 보존.
- defined: 공통 지시 뒤에 깊이 정의 한 문단만 추가.
- 각 조건의 neutral: 경로 방향 문장만 제거한 대조. defined-neutral에는 정의 문단은 남김.

같은 기준선의 모델·옵션을 수입하므로 다른 모델로 바꾼 뒤 이 계획을 실행하면 identity 검사에서 멈춰야 한다. 모델을 바꾸는 후속 실험은 별도 계약으로 진행해야 한다.

## 배정

2문제 × 2문단 조건 × 3방향 × 10seed = 120회. 모든 조건을 같은 배치의 고정 해시 순서로 섞는다. primary 방향 지정은 80회다. 중립 40회는 별도 대조다. 각 요청은 한 번 호출한다. 자동 재시도·warmup 추론·오답 수정·누락 경로 보충은 없다.

완전한 실행 순서 교차균형 또는 반복 안정성 연구는 아니다. 이전 v052와 시점이 다른 비교만으로 효과를 주장하지 않도록 original을 같은 새 배치에서 재실행한다.

## 응답 채점

형식, 최종 ID 존재, 증명 타당성, 실제 깊이, 방향 일치를 구분한다. 미실행/전송 오류/실행 identity 오류와 모델 형식·의미 오류를 구분한다. 파싱되지 않은 응답의 증명 의미는 None이며 거짓 증명으로 만들어 세지 않는다.

깊이는 사실 0, 규칙 적용 1+max(부모 깊이), 최종 노드의 깊이다. 사용되지 않은 우회 노드를 붙이거나 여러 대안 경로를 함께 출력하면 기존 엄격 증명 계약에서 실패한다. 전체 노드 수를 깊이로 사용하지 않는다.

최소/최대 깊이는 고정된 문제 정의를 오프라인 계산하여 채점에만 쓴다. 정답 깊이와 증명 경로를 요청에 전달하지 않는다. 최종 ID나 부모 참조를 고치는 후처리도 하지 않는다.

## 주지표와 분모

문제×문단 조건별 같은 seed의 shallow/deep 두 응답을 짝짓는다. 둘 다 유효하고 각각 최소/최대 깊이이며 실제 깊이가 서로 달라야 선택적 제어 성공이다. 조건별 10쌍이다. 일방향 성공 10/20이 양방향 성공 5/10으로 바뀌지 않는다.

원래 의미 측정은 요청 방향을 입력받아 실제 깊이를 바꾸지 않는다. 실제 깊이 계산 후 별도 단계에서 요청 방향과 비교한다.

중립 응답 하나를 최소/최대 역할에 각각 재채점한 평균과 방향 지정 성공률의 차이를 기술통계로 표시한다. 중립 재채점을 새로운 모델 호출이나 두 독립 표본으로 세지 않는다. 두 문제와 열 seed를 수백 개 독립 문제처럼 늘려 p-value를 만들지 않는다.

## 결과 해석

original 실패·defined 성공이면 정의 문단 추가 조건에서의 개선으로 본다. 의미 명확화, 길이, 주의 분배 등 내부 원인을 분리한 결과는 아니다. 둘 다 성공하면 original 성공도 인정하고 defined 독점 효과를 주장하지 않는다. 둘 다 고정 경로이면 정의 명시만으로 제어가 해결되지 않았다고 판정한다. 그 경우 규칙 순서 교환 같은 다른 원인 구별 실험은 별도 다음 단계다.

증명 유효성이 떨어지면 깊이 일치한 subset만 골라 성공을 보고하지 않는다. 미완료 실행은 전체 성공률과 인과 결론을 확정하지 않는다. A/M 제어, 통합 제어, 내부 hidden layer 제어 및 작은 모델의 고성능 모델 대체는 이번 측정 대상이 아니다.

## 자료 무결성과 재현

외부 계획을 실행 폴더 밖에 동결한다. 소스·옵션이 바뀌면 새 계획이 필요하다. 실행 전후 런타임 identity를 검사하고 요청/응답 바이트, 슬롯 순서, 이벤트 체인을 남긴다. loopback endpoint만 사용하고 자동 redirect/proxy와 재시도를 허용하지 않는다. 증거 ZIP은 실제로 넣을 바이트를 임시 폴더에서 재감사 후 생성한다. 전체 해시를 함께 고치는 공격까지 외부적으로 인증하는 서명 체계는 아니다.
