# 최종 검증 기록 초안 — 독립 감사 판정 대기

이번 산출물은 Qwen 직접 D 대조 실행 소스다. 과거 Gemma/K01 진단은 종료한 채, 기존 Qwen 구성 성공을 선택적 구조 제어 질문으로 연결했다. 연구·측정/인과·설계/구현·증거의 독립 초기 의견과 교차검토를 수행했고, 구성 선행 게이트에 관한 반론은 연구 복귀 결정서에 남겼다.

- 원자료: 논문 두 판본, 명세·simulator, v058~v063 핵심 원응답과 이전 단계형 실제 전달을 대조했다. 원문 집계 임시 오류와 교정은 CORRECTIONS.ko.md에서 구분한다.
- 코드: 실행과 요청/의미 채점 분리, 별도 독립 의미 계산, 원문·부분 실행 보존, 새 RunName/중복 실행 차단, 최대18호출, 한국어 보고서 재계산, 결정적 새 소스 ZIP을 구현했다.
- 합성 검사: 고정 경로·방향 반전·잘못된 부모·역순 노드·파싱 불가·부분 실패·후속 중단·재해시 변조를 시험했다. 실제12,674,642-byte 중첩 기준선, 한글·공백, native stderr/exit0·7을 확인했다. 현재 소스 CheckOnly16개, 새 빈 폴더 CheckOnly16개 통과. 같은 검사 재실행은 새 연구 표본이 아니다.
- 실제 모델: 이번 개발 중 추론0회, 다운로드·갱신·서버 시작0회. 영구 보존된 합성 실행의18회는 가짜 HTTP 응답이며 실제 모델 결과가 아니다.
- 연구 가설: 선택적 D/A/M·일반화·비용 우월성은 이번 개발에서 입증하지 않았다. 새 평가 두 구조는 설계자 선정 prospective 문제이며 외부 독립 holdout이 아니다.

완료 판정은 audit_input_r1.json에 묶인 봉인 소스의 독립 감사 결과와 감사 후 해시 검사를 확인한 FINAL_REVIEW.ko.md가 대신한다. 이 초안에는 감사 결과를 미리 채우지 않는다.
