## 2. 세 가설과 판단 범위

### H1 — 정확한 두 후보 계산이 제공되면 현재 선택 계약이 충분한가

`candidate_id`와 `correct_full`을 같은 문제·표시·seed·요구에서 비교한다. 후자는 두 후보의 정확한 전체 계산표를 외부에서 받는다. D 선택·양방향 선택·실제 graph 종단 및 양방향 종단을 따로 본다.

정확한 자료로 성공이 늘면 외부 정답 지원 패키지의 효용이다. 지원 없이 모델이 깊이를 계산하는 능력, 계산 오류만의 순수 인과 효과, 일반적인 ADM 제어의 완성을 주장하지 않는다. 정확한 자료가 있어도 선택이 틀리면 현재 계약에서 정확한 계산 제공만으로 충분하지 않다는 관측이다. v082와의 과거-현재 총계 차이 대신 이번 같은 배치 내 직접군과 비교한다.

### H2 — 같은 정답에서 긴 전체 계산표와 짧은 숫자 요약은 다르게 작동하는가

`correct_full`과 `correct_values`를 비교한다. D/W의 최종 숫자는 정확히 같다. 전체표는 facts/steps/goal_depth/rule_count를 포함하고 요약은 goal_depth/rule_count만 포함한다. 후보 대응·순서·내용·원문 문제·헤더·API·선택 스키마를 유지한다.

이 처치는 중간 구조 정보와 입력 길이를 함께 바꾼다. 토큰 수를 맞춘 길이 단독 효과나 모델의 attention 메커니즘을 식별하는 실험은 아니다. 짧은 자료에서 개선되면 해당 표현 패키지의 효과로 한정한다. 어느 쪽에서 실패해도 정확한 숫자가 항상 선택을 보장한다고 선언하지 않는다.

### H3 — 참고 숫자의 순서를 바꾸면 선택도 그 순서를 따라 바뀌는가

`correct_values`와 `swapped_values`를 비교한다. 후자는 요청 지표가 D이면 두 goal_depth만, W이면 두 rule_count만 교환한다. 요청하지 않은 지표, 후보 규칙, ID, 위치, 헤더, 스키마, seed, 옵션을 유지한다. 숫자는 여전히 두 후보에 적힌 숫자이며 실제 규칙의 참값과 반대다. 이 대조는 실제 관측의 사후 변조가 아니라 추론 전에 고정한 입력 실험이다.

두 군에서 선택 경로가 바뀌었는지뿐 아니라, 각각 제공된 숫자의 올바른 극값을 골랐는지와 실제 목표 지표를 맞혔는지를 함께 본다. 값 교환군은 선택 진단 전용이다. 잘못된 숫자를 따르는 일관성은 D 성공이 아니고, 원 문제의 올바른 경로를 유지하는 것은 실패로 벌점 처리하지 않는다. 어느 행동도 내부 메커니즘을 확정하지 않는다.

## 3. 네 군과 생성 범위

| 군 | 선택기 참고자료 | D 선택 | D 증명 생성 | W 선택 | W 증명 생성 |

공통 지정 경로 참조는 16개를 한 번만 생성한다. 총 선택 요청 384회, 본실험 증명 192개와 공통 참조 16개로 총 증명 208개다. 증명 미배정인 선택 조건은 192개다. 이를 실행 미관측·graph 실패·D=0으로 채우지 않는다.

D는 군별 32쌍, 위치×ID 네 표시 모두의 성공은 8묶음이다. W는 군별 16쌍과 4묶음이다. D/W 네 요구 모두의 정확성은 H03/H04의 군별 16조건에서 **선택만** 검사한다. W 종단을 실행하지 않았기 때문에 D/W 네 요구 종단 결과도 보고하지 않는다.

핵심 D 종단 비교는 직접군/정확전체/정확요약이다. 순서를 균형화한 네 선택을 먼저 실행한 뒤 배정된 각 군의 실제 선택으로 생성한다. 선택 답은 모든 군에서 candidate_id 하나다.

최대 추론 요청 1,628회, 모든 선택이 실제 요구 경로이면 1,580회, 모든 선택이 매핑되면서 생성 배정 경로가 최소 길이면 1,532회다. 선택 매핑 실패 시 실제 호출은 더 적을 수 있다. metadata 16작업을 포함한 최대 진행 슬롯은 1,644개다. metadata 한 작업은 여러 조회이므로 진행 슬롯을 HTTP 요청 수로 해석하지 않는다.

## 4. 자료 출처와 무보정

정확한 자료 8개(4구조×2후보)는 기본 규칙에서 계산하여 protocol.json에 사전 동결한다. 같은 자료를 두 seed와 모든 표시·요구에 재사용한다. 독립 검산기는 원자 의존 관계의 재귀 계산으로 이 자료를 다시 확인한다. 모델 계산표 호출은 0회다. 8개 통제 자료를 새 모델 관측으로 세지 않는다.

모델에 보이는 세 지원군의 설명은 동일하며 정확한 자료/교환군이라는 조건명을 노출하지 않는다. 모든 지원군에서 참고자료의 정확성을 보장하지 않고 원 문제를 검토할 수 있게 한다. 원 문제·후보를 제거하거나 참고 숫자를 반드시 따르도록 강제하지 않는다.

실제 모델이 반환한 선택 ID와 중간 생성 응답은 수정하지 않는다. 호스트의 정답 극값 선택은 금지하며, 모델이 고른 ID를 사전 후보에 대응하는 작업만 수행한다. 정답 부모 ID·완성 증명·후속 단계 정답을 제공하지 않는다. 제공 자료는 선택기에만 들어간다. 생성기는 기존 explicit_rule, 실제 선택 원문, 해당 군이 작성한 이력으로 실행한다. 외부 정답을 생성기에 전달하지 않는다.

H01~H04는 기존 진단 문제이며 새 독립 구조는 0개다. D는 고정 규칙 체계에서 실제 유효 증명 DAG의 목표 의존 깊이이며, W는 선택 진단이다. 원래 D=Decomposition 축을 재정의하지 않는다. 사람의 사고 깊이 전체·hidden state·A/M 축·모델 간 성능·비용 우월성은 이 배치의 측정 대상이 아니다.

## 5. 성공 판정과 분모

기존 실제 graph·모든 규칙 단계·부모·goal 조상·경로 충실성·실제 D 기준을 유지한다. 외부 계산표의 정확성을 모델의 추가 성공 계약으로 넣지 않는다. 지원군은 실험자 지원하의 성과로 명시한다.

선택 형식 실패, ID 매핑 실패, 잘못된 경로 선택, graph 생성 실패, 전송/identity/길이 문제, 실제 미관측과 사전 미배정을 구분한다. 한 군이 미관측이면 짝비교에서 상대 승리로 세지 않는다. 올바른 경로에 매핑된 하위집합만 골라 전체 정답률로 발표하지 않는다.

같은 표본의 seed·위치·ID 반복을 독립 문제로 보고하는 통계 검정은 하지 않는다. 각 가설에 대해 같은 배치의 승/패/동률/비교불가와 양방향·표시 전수 성공을 보고한다. 사전 성공 기준을 나중에 단일 방향 정답률이나 단순 반응 차이로 바꾸지 않는다.
