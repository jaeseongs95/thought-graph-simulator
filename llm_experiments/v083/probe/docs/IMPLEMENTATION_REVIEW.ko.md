# v083 구현 검토

## 유지한 기반

v082 배포본의 legacy Python 9개 파일을 바이트 그대로 보존했다. core/run/verify/launch의 무결성·잠금·가드·모델 identity·중단 보존 절차를 이어받았다. 실제 생성 프롬프트·스키마·현재 규칙 명시 방식·원문 전달·API 옵션은 유지한다. 기존 직접 선택군 요청은 v082 증거와 별도로 회귀 대조한다.

## 달라진 부분

- 모델이 계산표를 작성하는 단계와 profile 추가 계약을 제거했다.
- 정확한 후보 계산표 8개를 protocol.json에 고정했다. 생산 요청은 이를 읽고, 독립 검산은 원자 재귀 계산으로 같은 내용을 재구성한다.
- 네 선택군을 4×4 Latin 순환 순서로 균형 배정한다. 각 지표에서 각 군의 선택 호출 위치 빈도가 같다.
- 자료가 달라지는 지원군의 헤더는 동일하다. 정확전체→정확요약은 facts/steps만 제거하고, 정확요약→교환요약은 요청 지표의 두 숫자만 교환한다.
- D의 직접·정확전체·정확요약에만 graph를 생성한다. 그 외는 trial.generate=false이며 원래부터 생성 슬롯이 없다.
- 보고서는 미배정을 별도 상태와 0개의 배정 분모로 기록한다. 표시에서는 ‘배정 없음’으로 쓴다.
- 실제 선택 ID 원문은 생성기에 그대로 전달한다. support 자료는 전달하지 않는다.

## 시험의 범위

정상 합성 응답만이 아니라 첫 위치 고정·특정 ID 고정·W만 사용·D만 사용·전체 역방향·제공 숫자 추종·지원군 개선/악화·선택 형식 실패·부모 연결 오류·미관측을 검사한다. 실제 모델의 응답을 생성하거나 예측하는 시험은 아니다.

요청의 전체 바이트와 hash/dispatch/event chain을 함께 바꾼 변조도 독립 검산이 의미 불일치로 거부하는지 확인한다. 중단 시 미기록 응답과 이미 저장됐지만 이벤트에 확정되지 않은 응답을 구별한다. 로컬 HTTP 이외 접속·프록시·리다이렉션을 허용하지 않는다.

기존 v082의 독립 검산기를 해시 고정된 배포본에서 꺼내 기준 evidence를 읽기 전용 재감사한다. 과거 응답을 새 직접군 관측으로 대체하지 않는다. source.prior에는 기존 소스만 들어가고 기존 evidence는 외부 필수 입력이다.

## 해석 제한

정확한 정답 지원군의 성과는 모델 자력 깊이 계산 성과가 아니다. 이번은 계산 오류 교정 알고리즘이나 증명 부모 보정 기능을 개발하는 실험도 아니다. 선택기는 여전히 모든 출력 ID를 직접 선택해야 하고 생성기는 부모 연결을 직접 작성해야 한다. 값 교환은 거짓을 정답으로 채점하는 기능이 아니라 사전 입력 대조다.

헤더와 참고자료가 없는 직접군 대비 지원군은 추가 입력 패키지 처치다. 전체표/요약은 길이와 정보 형식이 함께 달라진다. 숫자 교환 대조만은 실제 요청에서 두 값 이외 모든 바이트를 유지한다. 내부 모델 메커니즘이나 독립 구조 일반화는 주장하지 않는다.
