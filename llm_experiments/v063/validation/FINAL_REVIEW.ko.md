# v063 완료 검토

v062의 실행 기록은 독립 검산과 일치하지만 전체 증명 성공은 0/40이다. 새 LLM 실험으로 넘어가지 않고, 실패 위치를 설명하는 v063 오프라인 소스를 작성했다.

## 결과와 해석

- 형식 40/40, 지정 최종 규칙 문자열 39/40, 목표 문자열 40/40이다. 이들은 증명 성공률이 아니다.
- 짧은 조건 16/20은 최종 부모 연결 밖에서만 논리 오류가 발생했다. 긴 조건에서 같은 분류에 속하는 1개는 지정 규칙 자체가 다르다.
- 원래 proof/strict/지시 이행은 모두 0/40, actual_D는 모두 null, 다음 단계 진입 판정은 false로 보존했다.
- 같은 문제의 반복 seed를 새 문제 표본으로 세지 않는다. 모델 능력, 출력 부담, 규칙 경쟁, 캐시의 원인은 이번 자료로 분리되지 않는다.

측정·인과·공학 관점의 독립 초기 검토 3건과 교차검토 1회를 수행했다. 최종 조상만의 깊이를 다시 매기자는 제안은 철회했고, 새로운 holdout 추론은 이번 범위에서 제외했다. 상세 주장·반박과 근거는 ../probe/docs/V062_ANALYSIS.ko.md에 있다. 토론의 통합은 메인이 맡았으므로 완전한 독립 판정이라고 표현하지 않는다.

## 소스와 실행 검증

새 소스 9개와 기존 의존성 360개를 담은 ZIP을 생성했다. 분석기, 별도 구현의 보고서 검산기, 입력 해시를 확인하는 실행 도구, Windows 실행기, 반례 시험과 문서를 포함한다. 기존 소스와 원자료는 보존했다. v063에서 실제 LLM 호출은 없었다.

|검사|실제 결과|
|---|---|
|원 v062 독립 재검산|842개 항목과 기준선 1,649개 항목, 차이 없음|
|v063 실제 원자료 진단 독립 대조|5,294개 항목, 차이 없음|
|원본 자체시험|10건 통과|
|ZIP 새 폴더 해제 후 자체시험|10건 통과|
|Windows PowerShell 오프라인 실행|통과|
|이전 360개 소스 바이트 대조|모두 동일|
|신규 소스 UTF-8·LF·AST / git diff --check|통과|

시험에는 부분 실행, 잘못된 참조, 순환, 불필요한 유효·무효 노드, 원자료·보고서 변조, 중복 JSON 키, NaN, 타입 혼동, 크기 제한과 기존 출력 보존이 포함된다. 합성 fixture는 실제 연구 결과에 합산하지 않았다. 이전 버전의 모든 회귀시험을 다시 실행한 것은 아니다.

실제 산출물은 ../results_llm/v063_forensics_01/의 analysis.json, independent.json, summary.ko.md, completion.json이다. validation/v062_reanalysis.json은 개발 중 초기 진단이므로 최종 보고서로 사용하지 않는다.

두 계산기는 기존 독립 검산 계약을 공유한다. 공통 명세 오류 가능성은 남는다. 예전 parse_error 설명 문구의 보증을 소급 확장하지 않으며 새 raw_parse_category를 원문에서 재계산한다. 해시 일치는 외부 실행 인증이 아니다.

## 최종 소스 감사와 한계 처리

작성·통합에 참여하지 않은 새 감사자가 고정 ZIP을 직접 검토했다. 판정은 pass_with_diagnostic이며 차단 결함 0개, 경미한 사항 1개다. 40개 원문 전체를 별도 계산해 differences=[]를 확인했다. 상세 기록은 SOURCE_AUDIT.ko.md와 source_audit_result.json에 있다.

D001은 채택했다. 같은 소스로 ZIP을 다시 만들면 엔트리 시간 때문에 ZIP 전체 해시가 달라지지만 370개 엔트리의 내용은 동일했다. 이번 고정 배포본의 내용·검산에는 영향이 없으므로 수정하지 않고 unresolved diagnostic으로 남긴다. ZIP 바이트까지 동일한 재빌드는 보장하지 않는다.

보증 범위는 cooperative-sealed / sealed-artifact-v1이다. 일반 검증 후 소스를 고정하고 새 감사자를 배정했으며 감사 후 메인이 ZIP 해시와 작업 소스 일치를 다시 확인했다. 같은 사용자 권한의 악의적 변경을 방어하는 외부 인증은 아니다.
