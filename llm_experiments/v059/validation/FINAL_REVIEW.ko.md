## 분석과 구현 검토

자료에서 틀릴 수 있는 판단을 기준으로 증거 출처, 측정, 논리 오류, 인과, 표본과 일반화, 실험의 정보가치, 구현과 실패 보존의 7개 관점을 도출했다. 측정·구성타당성, 인과·통계, 증거·구현 담당의 독립 초기 검토를 받은 뒤 주장별 반박과 원문 재계산을 대조했다. 후속 설계 합의는 후보 공개 후 진행했으므로 맹검 합의는 아니다.

새 소스도 같은 관점에서 검토했다. 실제 D와 choice implied_depth를 분리하고, 관측·미측정 분모를 보존하며, 조건 간 비교와 조건별 반복 변동을 따로 집계한다. ABBA/BAAB는 블록 내부 균형을 제공하지만 전역 이력과 순수 위치 인과를 통제했다는 주장은 하지 않는다.

## 검증의 경계

소스 검증은 실제 LLM 40회 실험의 결과를 대신하지 않는다. 합성 응답은 synthetic_fixture로 구분했고 연구 성과에 합산하지 않았다. 과거 전체 모델 실행을 테스트에서 재현하지 않으며, 앞 버전 검산을 대체하는 fixture의 한계는 실제 v058 자료에 대한 별도 생산·독립 import 검사로 구분했다.

생산 계산기와 독립 계산기는 구현을 나눴지만 문제 명세와 일부 앞 버전 독립 도구를 공유한다. 해시 일치는 외부 실행 인증이 아니며 캐시나 내부 사고 과정의 인과를 입증하지 않는다.

Python 캐시의 삭제는 자동 승인 검토에서 정책상 차단됐고 구체적 사유는 반환되지 않았다. 삭제를 우회하지 않았으며 캐시는 소스 ZIP과 manifest에서 제외했다.
