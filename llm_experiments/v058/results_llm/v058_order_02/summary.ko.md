choice의 implied_depth는 문제에 대응하는 선택 깊이이며 생성된 증명의 D가 아니다. 실제 D는 graph 원문에서 계산한다.
같은 seed의 재실행을 독립 문제 표본으로 합산하지 않는다. 순서 차이가 관측돼도 특정 캐시나 내부 처리 원인을 확정하지 않는다.
