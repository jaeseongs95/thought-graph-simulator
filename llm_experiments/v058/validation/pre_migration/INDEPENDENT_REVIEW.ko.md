# 독립 관점과 최종 조치 기록

논문·구성타당성 담당, 원문·통계 담당, 증거·구현 조정자가 각각 자료를 읽고 판단한 뒤 서로의 반례를 교차검토했다. 별도 구현 담당이 v058 생산 소스를 작성했고, 조정자가 독립 검산기를 작성했다. 논문 담당은 구현하지 않은 최종 소스와 검산기를 다시 검토했다. 에이전트 간 독립 검토이며 외부 인간 심사나 독립 연구기관의 검증을 뜻하지 않는다.

## 관점 사이의 주요 이견

첫 후속 후보는 실제 선택 ID를 다음 증명 생성에 넘기는 대조였다. 원문 담당이 seed parity·실행 선후·성패가 함께 움직이는 조건을 발견했고, 논문 담당은 그 자료로 선택 안정성을 전제하면 안 된다고 반박했다. 960회 전달 실험도 과거 선택의 교락을 풀지는 못한다는 의견을 채택해, 같은 seed의 양 선후를 재현하는 80회 진단으로 바꿨다.

부모 오연결 반례는 마지막 규칙 선택과 증명 구성을 분리해야 한다는 근거로 남겼다. rule 위치 편향과 내부 망각을 단정하지 않았으며, 다음 소스는 캐시 초기화나 일반 능력 비교를 주장하지 않는다.

## 최종 감사에서 발견한 결함과 조치

| 지적 | 확인 근거 | 최종 처리 |
|---|---|---|
| 보고서의 실행 이력 인과 표현 | 관측은 선후와 성패의 연관성이며 seed 교락이 남아 있음 | 연관성 표현으로 수정, 독립 재확인 |
| 선택 ID 변화 지표 누락 | 프로토콜은 같은 seed의 ID 변화 평가를 요구했으나 초기 report에 없음 | 두 ID, 변화 여부, 비교 가능 분모와 완료 조건부 비율 추가 |
| 독립 검산기가 기준선 실패를 무시 | `complete=False`, 불일치 반환을 주입해도 PASS하는 반례 재현 | 완료·불일치·int 480 검사 추가, 회귀 반례 6종 거부 |
| 독립 검산기의 endpoint 결합 누락 | endpoint를 다른 호스트로 바꾸고 manifest 재해시해도 PASS | 동결 endpoint 정규화·결합 검사 추가, 같은 반례 거부 |
| control 필드 자료형·목록 검사 차이 | 생산 계약보다 독립 검산기의 수용 범위가 넓음 | 버전·정확한 필드 집합·정수·일정 정규 비교 보강, 반례 3종 거부 |

수정 후 독립 소스·해석 검토는 미해결 지적 없이 수용 가능하다고 판정했다. 그 검토자는 당시까지 36개 시험 로그를 확인했고, 이후 추가한 회귀시험을 포함한 39개 전체 통과는 시험 담당자가 확인했다. 최종 압축해제 시험은 조정자가 별도로 실행해 `release_verification.json`과 로그에 기록한다.

## 검증 범위

최종 원본 소스 자체시험은 39/39 통과, exit 0이다. 가짜 HTTP의 완료·부분 실행과 v058 생산 감사·ZIP 생성·독립 검산을 연결했다. 과거 v057 기준선 전체 검증만 mock했으며, 실제 제출 다섯 파일의 전체 생산·독립 재감사와 최종 계획 준비는 별도로 실행했다.

실제 LLM 추론은 새로 실행하지 않았다. 따라서 연구 결론은 제출된 v057 관측에만 근거한다. 모든 원자료와 기존 추적 파일을 보존했고, 입력 다섯 파일의 최종 해시 일치 및 변경 범위는 `scope_and_source_validation.json`에 기록했다.
