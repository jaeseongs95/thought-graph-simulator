- 선택 출력 지시와 스키마만 군별로 다르다. 후보 ID는 새 군의 입력에도 남는다.
- 생성기는 explicit_rule 고정. 기존 지시·스키마·현재 규칙 재표시를 유지한다.
- 잘못된 선택과 중간 원응답을 그대로 전달한다. 출력 형식의 차이가 생성 입력에 남는 것을 숨기지 않는다.

## 판단 기준

주평가지표는 군별 D 양방향 종단과 같은 조건의 군간 짝비교다. 기존 단일 표시의 부분 성공과 네 표시 전수 성공은 따로 보존한다. W 결과를 D 성과에 합산하지 않는다.

| 관측 | 허용할 해석 | 금지할 확대 |
|---|---|---|
| 규칙 목록군이 정확한 선택·D 양방향 종단을 늘림 | 해당 계약에서 선택 출력 방식의 개선 효과 | ID 매핑만이 실제 내부 원인이었다 |
| 실제 경로 복사는 되지만 첫 위치 고정 유지 | 출력 표현을 바꿔도 해당 선택 병목 유지 | 모델이 유효 graph를 전혀 만들 수 없다 |
| 목록의 누락·혼합·순서 오류 증가 | 목록 출력 계약의 실행 가능성 제한 | D를 계산할 능력이 전혀 없다 |
| 매핑된 하위집합의 정오만 개선 | 해당 조건부 결과 | 실패한 전체 배정을 삭제하고 일반 개선 선언 |
| 규칙 수는 제어하고 D는 제어 못함 | 이 진단의 지표별 차이 | 일반적 인지 난이도 순위 |
| 유효한 두 graph가 역방향 | 생성 성공·요구 D 실패 | D 종단 성공 |
| 한쪽 미관측 | 비교 불가 | 다른 쪽의 단독 승리 |

`rule_ids` 순서가 다르지만 원소는 동일한 경우는 진단에만 기록한다. 정렬해서 실행하거나 성공으로 보정하지 않는다. 목록의 해석이 불가능하면 실제 D/W는 null이며, 모델이 작성하지 않은 증명을 호스트가 대신 완성하지 않는다.

정상 완료 응답의 출력 형식·매핑 실패, 구조적 논리 실패, 미실행·전송·identity·길이 종료는 별도 상태로 기록한다. 성공/실패/미측정 분모와 원문 상태를 함께 제공한다. 부분 응답을 오답·깊이 0으로 임의 채우지 않는다.
