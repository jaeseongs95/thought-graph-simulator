# v0.4.1 변경 내역

## 확인된 버그

`calibration.py`: 최종 노드만 schema인 혼합 도식을 all_schema=true로 통과시키던 거짓 양성 수정. 각 노드의 종류와 전체 표현 의미를 모두 검사한다. 최종 A, 모든 종류 일치, 전체 의미 유효성의 비교값을 나누었다. 기존 calibration 원문 24건의 최종 판정은 변하지 않는다.

## 진단

`evidence.py`: core/기존 audit을 호출하지 않고 원문 규칙과 실제 부모 명제를 대조하는 별도 검사. 노드별 기대/실제/누락/혼입, 선택 부분 유효성과 무관 노드를 기록한다. 정답 생성/자동 복구가 아니다.

`diagnostics.py`, `calibration.py`, `calibration_v4.py`: 상세 근거 진단과 실제 제출 범위/종류를 노출한다. 문자열 JSON format도 안전하게 구별한다.

`report.py`, `runner.py`: 전체 PASS 여부와 성공 건수를 분리해 표시한다. 상세 진단 CSV를 추가한다. 원래 성공 기준은 유지한다.

## 원인 분리 계획

`causal_probe.py`: 기존 모델을 사용하는 12회 별도 진단. baseline 요청은 원래 요청 생성기를 그대로 사용한다. 비교 단위는 프롬프트 묶음 또는 format 하나다. 기존 실험의 출력 강제 조건을 몰래 바꾸지 않는다.

## 시험 및 변경하지 않은 범위

`tests/test_v041.py`: 18개 신규 반례/관측/계약/모의 API 시험. 기존 121개와 합쳐 139개 통과.

`adm_minimal.py`는 수정하지 않았다. 사용자가 제공한 바이트와 SHA-256 일치를 검사했다. `model_policy.py`, 기존 prompt 프로필, 통합 문제, 기본 모델/샘플링은 변경하지 않았다. 저장된 69개 기본 요청은 수정본에서 바이트가 동일하다. 69개 상태와 오류도 동일하다. 실제 모델 호출을 실행해 성능 개선을 확인한 것은 아니다.
