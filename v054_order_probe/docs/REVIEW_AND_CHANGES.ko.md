# 검토 관점의 대립과 수정 기록

## 1. 검토 방법

사용자가 제공한 이전 MD의 흐름에 따라 원문·계획·실행 소스·채점·독립 계산을 대조한 뒤, 서로 다른 심사 기준에서 결론을 검토했다. 별도 외부 심사자나 다중 에이전트를 호출하지 않았다. 구현 독립성은 생산 채점기를 import하지 않는 별도 검증 코드와 반례 시험에 근거한다.

## 2. 현재 v053 해석에서 대립한 쟁점

| 관점 | 먼저 검토한 주장 | 자료로 판정한 결과 |
|---|---|---|
| 실행·데이터 | 첫 추론 전 중단의 재발인가 | 120회 완료, HTTP/identity/event/manifest가 재감사에 부합 |
| 측정 | D 실패가 채점기의 착오인가 | 전체 report 재생성과 두 별도 의미 계산이 일치. 이번 결과를 바꿔야 할 측정 결함은 발견하지 않음 |
| 성공 기준 | 방향 일치 40/80이면 절반의 제어 성공인가 | 문제별 같은 경로가 한 방향에만 맞았음. 선택적 대응은 0/40 |
| 개입 효과 | 정의 명시로 해결됐는가 | 선택적 성공 증가 없음. defined K01 shallow에서 미등록 규칙 4건이 추가됨 |
| 인과 | 규칙 순서가 실제 원인인가 | 현재 경로와 제시 순서의 정합성만 있음. 순열 개입은 아직 실제 Qwen에서 실행하지 않음 |
| 연구 핵심 | 정답 경로를 대신 골라서 성공을 확보해도 되는가 | 호스트 선택은 이번 외부 생성 제어 질문을 바꿈. 규칙 내용과 평가 기준을 고정한 대조를 채택 |

합의는 현재 실패를 인정하면서 규칙 블록 순서의 효과를 분리하는 것이다. 새 요청도 각 순서 안에서는 고정 문제·고정 목표에서 방향만 바꾸는 짝비교를 유지한다.

## 3. 보존과 변경

v047~v053 생산 코어 71개 파일은 바이트 단위로 유지했다. 새 `order_probe_v054` 모듈과 새 tests/tools/docs/windows 실행 진입점만 추가했다. v053 결과를 소급 수정하지 않았다. v053에서 교정된 최종 참조 존재 판정과 엄격한 D 측정은 그대로 사용한다.

새 계획은 v053 완료 원문을 기준선으로 재감사한다. 점수는 수입 게이트가 아니다. 저장 summary와 원문 재계산이 다르면 거부하는 검사를 추가했다. 보고서에는 방향 제어, 순서 효과, 두 순서에서의 제어 유지, 중립 대조를 별도로 기록한다.

## 4. 개발 중 실제 발견하고 수정한 것

첫 신규 시험 실행은 73개 중 1개가 실패했다. 새 Markdown 보고서에 `neutral` 행은 있었지만, 한국어 중립 대조 설명과 분모 안내가 누락된 것이 원인이었다. 시험을 삭제하거나 완화하지 않고, 방향 80회/중립 40회 분리 및 같은 중립 응답의 재채점 설명을 넣었다. 중립 대비 평균 차이도 표에 유지했다. 이 교정은 연구 채점이나 성공 분자를 바꾸지 않는다.

별도 v053 재분석 스크립트의 초안에서는 구버전의 graph_only `role_match=null`을 새 버전의 D 전용 bool과 비교했다. 이 필드들은 같은 정의가 아니므로 비교를 폐기했다. 두 버전 원문 모두를 동일한 독립 D 기준으로 재계산하도록 고쳤고, 40/40 대응 결과가 일치했다. 이것은 첨부된 v053 소스의 결함이 아니라 이번 분석 코드 작성 중 발견한 비교 기준 오류다.

미등록 규칙 `k1`·`k1_7`을 `k17`로 바꾸는 수정, final ID 추정, 불필요 노드 제거, 역할을 무시하는 응답을 성공으로 올리는 변경은 하지 않았다.

## 5. 반례 시험의 목적

완벽한 방향 추종기는 두 순서에서 모두 성공해야 한다. 항상 얕은 경로만 내는 응답은 유효하더라도 제어 성공이 없어야 한다. 첫 규칙 블록만 따르는 응답은 순서 효과가 크더라도 제어 성공으로 세지 않아야 한다. 한 순서에서만 제어되는 응답은 전체 순서 견고성 성공이 아니어야 한다.

없는 final, 미등록 규칙, 길이 제한 종료, HTTP 실패, 모델 identity 불일치, raw/요청/source 변조, 해시를 다시 만든 계획 변경, 저장 집계 조작도 따로 검사한다. 시험 서버의 성공은 실제 Qwen 결과와 다른 `synthetic_fixture` 출처로 남긴다.
