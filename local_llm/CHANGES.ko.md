# v0.4.6 변경

## 변경한 것

- `operator_audit.py`: 원문 16건과 승인된 v0.4.5 소스 39개를 검증하고 기존 채점을 재현합니다. 보존한 Python은 실행하지 않습니다.
- `operator_probe.py`: 단일 출력 과제와 단일 게이트를 구분합니다. `a AND (NOT b)`만 실패한 경우를 원시 연산 실패로 분류하지 않습니다. 미완료는 별도 표시합니다. 기존 `all_atomic_correct` 키는 파일 호환성용으로 유지합니다.
- `composition_probe.py`: 실제 NOT 결과를 다음 AND 입력에 그대로 넣는 두 단계 실행을 구현합니다. 모든 중간 단계와 최종값을 각각 평가합니다.
- `runner.py`, `task_evidence.py`: 새 계약의 요청·채점·진단 라우팅만 추가했습니다.
- `approved_v045.py`, 원문 fixture, `test_v046.py`를 추가했습니다.

## 변경하지 않은 것

- `adm_minimal.py`는 수정·배포하지 않습니다.
- 기존 v0.4.5의 모델, 샘플링, 입력, 채점표 및 응답 15/16 판정은 유지합니다.
- 새 실행에서도 정답을 프롬프트나 schema에 넣거나, 틀린 NOT를 코드에서 보충하지 않습니다.
- 과거 입력이나 실패를 새로운 성공으로 덮어쓰지 않습니다.

이번 자료에서 정상 응답을 오채점한 결함은 발견하지 못했습니다. 변경은 진단 분류와 실행 구조입니다. 모델 가중치를 고친 것은 아닙니다.
