# v0.4.6 추가 실행 계약

`composition-v046`는 `operator-v045` 응답과 분리된 진단입니다.

1. 네 a/b 입력과 원래 모델·서버·샘플링을 고정합니다. 이전 호출에서 모델이 낸 a/b를 그대로 사용합니다.
2. 표기 대조는 `(a AND (NOT b))`를 `((NOT b) AND a)`로 바꿉니다. 그 밖의 HTTP 요청은 동일합니다.
3. NOT 4개 응답은 새로 생성합니다. 형식이 맞는 오답도 다음 단계에 전달합니다.
4. 후속 AND에서는 원래 a와 실제 NOT 반환값을 입력합니다. 모델별 답을 받기 전에 다음 입력을 정답표로 채우지 않습니다.
5. NOT 형식 실패는 자식 실행을 차단하되 네 파이프라인의 분모를 유지합니다. 올바른 bool 형식의 오답은 수정하지 않습니다.
6. 후속 게이트 자체의 조건부 정답, 최종 복합식 정답, 전체 단계 통과를 구분합니다. 상쇄 오류는 전체 단계 통과가 아닙니다.
7. 원본 16건의 성공/실패는 보존합니다. 새 결과의 호스트 제공 그래프, 호출 수·시간·토큰을 별도로 기록합니다.
8. 원시 연산 success는 합성식 일반화 success와 동일하지 않습니다. 또한 구체적 네 행은 모집단 성능 추정치가 아닙니다.

호스트가 제공한 NOT→AND 그래프, a/b 변수 대응, 단계 경계를 모델이 독자적으로 발견한 성과로 세지 않습니다.
새 게이트 실행과 원래 A/D/M 연구의 종단 간 검증은 다른 평가 범위입니다.

이전 명령의 계약은 `HISTORY_v045_PROTOCOL.ko.md`에 보존했습니다.
