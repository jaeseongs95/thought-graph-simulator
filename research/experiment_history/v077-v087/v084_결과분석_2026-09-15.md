## 4. 신규 구조별 판정

D와 W의 표기 순서는 shallow 경로 / deep 경로다. W는 규칙 수다.

| 구조 | D | W | 직접 양방향 | 지원 양방향 | 지원−직접 |
|---|---:|---:|---:|---:|---:|
| T01 | 2 / 3 | 4 / 4 | 0/8 | 6/8 | +75.00%p |
| T02 | 3 / 4 | 4 / 4 | 0/8 | 3/8 | +37.50%p |
| T03 | 3 / 4 | 5 / 5 | 0/8 | 5/8 | +62.50%p |
| T04 | 3 / 4 | 5 / 5 | 0/8 | 4/8 | +50.00%p |
| T05 | 2 / 3 | 4 / 3 | 0/8 | 2/8 | +25.00%p |
| T06 | 3 / 4 | 5 / 4 | 2/8 | 3/8 | +12.50%p |
| T07 | 3 / 4 | 5 / 4 | 0/8 | 4/8 | +50.00%p |
| T08 | 3 / 4 | 5 / 4 | 1/8 | 3/8 | +25.00%p |

T01~T04의 같은 규칙 수 가족은 직접 0/32 → 지원 18/32로, 구조 동일 가중치 차이는 +56.25%p다. T05~T08의 규칙 수 역전 가족은 직접 3/32 → 지원 12/32로, 차이는 +28.125%p다.

이 결과를 ‘규칙 수가 많은 경로를 깊은 경로라고 센 것’으로만 설명할 수 없다. 동일 W와 역전 W 양쪽에서 실제 D 방향에 맞는 유효 graph의 종단 성공이 관측됐다. D는 고정 primitive rule 체계에서 초기 사실 0, 유도 결과 `1 + max(전제 depth)`로 다시 계산했다.

사전 주평가의 실제 계산은 다음과 같다.

```text
구조별 지원−직접 pair 성공 수: [6, 3, 5, 4, 2, 1, 4, 2]
구조별 분모: 각 8쌍
동일 가중치 평균: (6+3+5+4+2+1+4+2) / (8×8)
                 = 0.421875
                 = +42.1875%p
```

문제 수는 8개다. 각 문제의 2 seed×4표시를 8개의 독립 문제로 다시 세지 않는다. 신규성은 공통 사실·목표를 공유하는 두 proof DAG의 쌍 단위로 동결 계획과 독립 검산에서 확인했다. 기존 구조와 부분 모티프를 공유할 수 있으며, 무작위 IID 문제 표본은 아니다.

## 5. 표시 강건성은 왜 실패했는가

### 5.1 지원군의 모든 선택 오류는 두 번째 정답을 놓친 경우

지원군 D 선택 오류는 30/128이다. 30건 모두 실제 정답이 두 번째 후보인데 첫 번째 후보를 골랐다. 그러나 단순한 위치 편향으로만 요약하면 중요한 ID 차이를 놓친다.

| 정답 위치 | 정답 ID | 선택 성공 |
|---|---|---:|
| 첫 번째 | route_0 | 32/32 |
| 첫 번째 | route_1 | 32/32 |
| 두 번째 | route_0 | **4/32** |
| 두 번째 | route_1 | **30/32** |

첫 번째가 정답인 64건은 전부 맞혔다. 두 번째가 정답일 때는 route_1이면 대부분 성공하지만 route_0이면 대부분 실패했다. 따라서 **위치와 ID의 조합에 따른 선택 차이**가 직접 관측된다.

### 5.2 네 표시별 수치

각 방향별 분모는 8개 구조×2개 seed = 16이다.

| 첫 후보 → 둘째 후보 | shallow 선택 | deep 선택 | 양방향 선택 | 양방향 종단 |
|---|---:|---:|---:|---:|
| 얕은 route_0 → 깊은 route_1 | 16/16 | 14/16 | 14/16 | 12/16 |
| 얕은 route_1 → 깊은 route_0 | 16/16 | **0/16** | **0/16** | **0/16** |
| 깊은 route_0 → 얕은 route_1 | 16/16 | 16/16 | 16/16 | 14/16 |
| 깊은 route_1 → 얕은 route_0 | 4/16 | 16/16 | 4/16 | 4/16 |

두 번째 줄에서는 요구를 deep으로 바꿔도 모든 구조·seed에서 첫 번째 얕은 route_1을 골랐다. 이 표시를 포함해야 하므로 문제×seed 단위의 네 표시 전부 통과가 0/16이 된다. 무작위로 드물게 틀린 사례가 각각 흩어진 것과는 다른 패턴이다.

### 5.3 ID만 바꾼 원요청 대조

T01 / seed 64001001 / 얕은 경로가 첫 번째인 조건에서:

```text
깊은 경로 요구

표시 A:
첫째 route_0: D=2, W=4
둘째 route_1: D=3, W=4
응답: {"candidate_id":"route_1"}  → 실제 깊은 경로 선택 성공

표시 B:
첫째 route_1: D=2, W=4
둘째 route_0: D=3, W=4
응답: {"candidate_id":"route_1"}  → 실제 얕은 경로 선택 실패
```

두 입력의 규칙·깊이·후보 순서·요구 방향·seed·API 옵션은 같고, 후보 및 해당 측정표의 ID 연결만 일관되게 교환됐다. 원문 선택 응답 두 개는 [선택 A](v084_review/outputs/selected_raw_examples/t003_correct_values_select/response.raw.json)와 [선택 B](v084_review/outputs/selected_raw_examples/t004_correct_values_select/response.raw.json)에 보존했다.

지원군 D에서 이런 ID-only 64짝을 대조했을 때 26짝에서 선택한 물리적 경로가 바뀌었다. 경로와 ID의 연결은 유지하고 배열 위치만 바꾼 별도 64짝에서는 30짝에서 경로가 바뀌었다. 두 분석은 같은 원실험 응답의 서로 다른 짝짓기이며 추가 추론 표본이 아니다.

### 5.4 관찰과 원인 해석의 경계

확인된 것은 **정확한 수치가 있어도 의미 보존 표시 변경이 선택을 바꾼다**는 점이다. 제공값 자체의 오류나 JSON 파싱 실패는 이 배치의 선택 실패 설명이 아니다. 수치−후보 ID 연결, 위치 단서, ID 문자열 처리 등은 구분할 다음 원인 후보지만, 특정 hidden-state 동작이나 디코더 내부 원인을 이번 기록으로 식별한 것은 아니다.

또한 이 정도의 순서·ID 효과가 있다고 해서 주평가의 8개 구조 개선을 삭제할 이유는 없다. 반대로 그 개선이 있다고 표시 불변성 실패를 무시할 수도 없다.

지원군의 종단 실패 38건 중 선택 오답이 30건(약 78.95%)이다. 선택을 정확히 했지만 생성이 실패한 것은 8건이다. 그래프 생성기를 바꾸기만 해서는 이미 다른 경로를 선택한 30건을 요구 D 성공으로 만들 수 없다.

### 6.2 전체 생성의 오류

본실험 256건과 공통 참조 32건을 합치면 graph 생성은 **267/288 성공, 21/288 실패**다.

| 단계 | 유효 | 무효 |
|---|---:|---:|
| 초기 사실 | 287/288 | 1 |
| 규칙 적용 | 1,237/1,259 | 22 |
| 최종 ID 지정 | 288/288 | 0 |

무효 graph 21개 전부에 premise_counter_mismatch가 있다. 이 중 하나는 중복 node ID도 있고, 하나는 등록되지 않은 초기 원자도 있다. 따라서 ‘모두 부모 연결 오류만 있었고 다른 오류는 없었다’고 단순화하지 않는다.

중복 ID가 있었던 T05 직접군 1건은 생성 노드를 동일 ID로 덮어써 고친 것이 아니라 중복 자체를 실패로 보존했다. T07 공통 참조의 1건은 초기 사실 원자를 잘못 적은 뒤 규칙 연결도 틀렸다. 이 때문에 이번 초기 사실 성공은 v083처럼 100%가 아니다.

### 6.3 T02 대표 실패

신규 T02는 이전의 H02와 이름만 비슷한 별개의 구조다. 이번 T02에서 자주 틀린 규칙은:

```text
b52: O84 → O27
```

이력에는 `n004=O84`가 있었지만 실제 원응답은 다음과 같다.

```json
{"node":{"atom":"O27","id":"n005","parents":["n001","n002"],"rule":"b52"}}
```

`n001=O92`, `n002=O87`이므로, 필요한 중간 전제 O84 대신 다른 초기 사실 두 개를 연결했다. 출력 atom과 rule ID가 맞아도 규칙 적용은 무효다. 뒤의 최종 노드가 goal을 가리켜도 전체 증명 실패를 덮지 않는다.

원문: [요청](v084_review/outputs/selected_raw_examples/t022_correct_values_rule_01/request.wire.json), [응답](v084_review/outputs/selected_raw_examples/t022_correct_values_rule_01/response.raw.json).

전체 T02 graph 36건 중 12건이 실패했다. T02의 shallow D=3 경로는 16/20, deep D=4 경로는 8/16 성공했다. 반면 T03의 D=4는 17/17, T04의 D=4는 20/20 성공했다. 이 빈도는 본실험과 참조를 포함한 반복 관측 합계다. **D=4라는 깊이 자체로 생성 가능/불가능을 나누는 설명은 맞지 않는다.**

공통 지정 경로 참조는 31/32 성공이다. 8개 구조의 shallow/deep 16경로 각각에서 최소 한 번의 유효 생성이 있었다. 후보 선택을 거치지 않고 경로를 지정하면 생성은 대체로 성립하지만, 참조를 본실험 양방향 제어 성공으로 합산하지 않는다.

### 6.4 같은 경로·동일 첫 요청에서도 생성 결과가 갈림

같은 조건에서 두 군이 같은 경로를 고른 경우는 82짝이다. 이 중 79짝은 생성 성패가 같고 3짝은 달랐다.

| 단위 | 구조 | 직접 생성 | 지원 생성 |
|---|---|---|---|
| t139 | T06 | 실패 | 성공 |
| t161 | T07 | 실패 | 성공 |
| t194 | T08 | 성공 | 실패 |

세 경우 모두 최초 facts 요청 바이트가 동일했지만 facts 응답에서부터 node ID 문자열이 달라졌다. 첫 응답은 양쪽 모두 의미적으로 유효했고, 서로 다른 이력이 뒤의 요청으로 전달됐다. 따라서 모든 생성 차이를 수치 지원의 직접 효과로 돌리거나, 같은 seed이면 산출물이 반드시 같다고 취급해서는 안 된다. 응답 차이와 후속 실패의 기록은 확인했지만, 차이를 만든 내부 실행 원인은 확인하지 않았다.

세 사례의 최초 분기와 원문은 [파생 분석의 same_route_comparisons](v084_review/outputs/derived_analysis.json)에 보존했다.

## 7. W 보조 대조

| W 지표 | 직접군 | 지원군 |
|---|---:|---:|
| 선택 | 42/64 = 65.63% | 38/64 = 59.38% |

| 네 표시 전체 양방향 선택 | 0/8 | 0/8 |

W 선택은 지원으로 높아지지 않았다. 같은 조건에서 직접만 성공 12건, 지원만 성공 8건으로 순감 4건이다. 따라서 ‘정확한 값을 주면 모든 지표 선택이 개선된다’는 결론은 지지되지 않는다.

T05~T08에서 D-small / D-large / W-small / W-large 네 요구를 모두 맞춘 문제×seed×표시 묶음은 직접 0/32, 지원 8/32다. 지표를 구별하는 부분 성공은 관측되지만 안정적인 전조건 구별은 아니다. W는 선택만 배정했으므로 종단 0점도, 미실행 실패도 아니며 D 종단에 합산하지 않는다.

v083 숫자들은 이전 답변에서 재인용하지 않고 v084 번들에 보존된 v083 evidence의 summary.json을 다시 읽었다.

## 10. 현재 연구 주장과 다음 판단

현재 결과에 맞는 연구 기술은 다음과 같다.

> 같은 문제·목표·primitive rule 체계를 고정하고 v083의 선택·생성 계약을 유지한 신규 구조쌍 8개에서, 정확한 외부 D/W 정보의 제공은 실제 proof DAG의 양방향 D 종단 성공을 직접군 3/64에서 지원군 30/64로 증가시켰다. 구조별 동일 가중치 효과는 +42.1875%p였고 8개 구조 모두 개선됐다. 그러나 후보 위치·ID 변경에 대한 전표시 불변성은 확보되지 않았으며, 잔여 선택 오류는 특정 위치·ID 결합에 집중됐다.

외부 정답 지원을 받은 선택·종단 성과이며 자력 D 계산을 새로 측정한 실험은 아니다. 결론은 이 사전 고정 구조집합에 대한 것이다. A/M 독립성·모델 내부 계산 깊이를 추가로 시험한 것은 아니다.

**다음 실험의 우선순위에 대한 판단:** 생성기 전면 변경보다, 정확한 값의 크기 비교와 그 결과의 후보 ID 연결 중 어디에서 표시 의존성이 생기는지 분리하는 쪽이 이번 실패 분포에 맞다. 현재 직접/지원 대조와 생성 계약은 비교 기준으로 보존해야 한다. 목표 지표도 특정 표시의 최고 성적이 아니라 의미 보존 표시 변환에 대한 선택·실제 D 종단의 유지 여부여야 한다.

같은 T01~T08로 후속 원인 진단을 수행한다면 이제는 관측된 진단 집합이지 새 holdout이 아니다. 표시를 바꾸며 성공한 것만 채택하는 탐색으로 바꾸지 말고, 비교할 조건·종료 기준을 먼저 고정해야 한다. 이 분석에서는 v085를 작성하거나 추가 실행하지 않았다.

## 12. 자료 구성과 재현

- `outputs/raw_audit.json`: 별도 원응답·단계·pair 검산 범위와 판정.
