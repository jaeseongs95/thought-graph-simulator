## 1. 판정

**사전 주가설인 두 생성 지원의 결합 효과는 이번 배치에서 지지되지 않았다. 오히려 실제 D 양방향 종단은 기준군 49/64에서 결합군 13/64로 감소했다. 구조별 동일 가중치 효과는 −56.25%p다.**

`node_inventory` 단독은 51/64로 기준군보다 2쌍 높았으나, 신규 성공 7쌍과 기존 성공 소실 5쌍이 함께 있었고 국소 규칙 진단은 134/140으로 동일했다. 현재 결과만으로 기본 생성기로 승격할 충분한 근거가 없다.

`allocated_id` 단독은 11/64다. 지정한 새 ID를 쓰지 못해 계약 점수만 낮아진 것이 아니다. 두 ID 지원군의 규칙 출력 **1,400/1,400개가 지정 ID를 지켰지만**, 실제 graph에서 부모 참조가 누락되거나 틀렸다. `missing_parent`가 있는 graph는 기준군·노드 표군에서 0개, ID군에서 66개, 결합군에서 62개다.

가장 중요한 관측은 **현재 노드의 ID는 정확히 출력하면서, 이후 부모에는 그 ID가 아니라 원자 이름을 출력하는 경우가 많았다는 것**이다. 또한 국소 규칙 진단의 선행 이력에는 새 할당 ID가 전혀 없었다. 따라서 그 진단에서의 높은 점수는 새 ID를 후속 규칙에서 재참조하는 능력을 시험한 결과가 아니다.

## 5. ID를 정확히 할당했는데 왜 graph는 실패했는가

### 5.1 실패의 관측 위치

두 ID 지원군의 규칙 출력은 진단까지 포함해 **1,400/1,400이 지정된 새 ID를 준수**했다. 현재 ID 충돌을 없애려는 사전 제약은 지켜졌지만, 기존 노드를 부모로 참조하는 작업은 별도로 남아 있었다.

| 종단 규칙 지표 | 기준 | 노드 표 | 새 ID | 결합 |
|---|---:|---:|---:|---:|
| 유효 규칙 단계 | 542/560 | 543/560 | 352/560 | 371/560 |
| `missing_parent`가 있는 graph | 0 | 0 | **66** | **62** |
| `missing_parent` 규칙 단계 | 0 | 0 | **164** | **161** |
| 그중 누락 참조 문자열 전부가 기존 원자와 정확히 일치 | 0 | 0 | **150** | **151** |

마지막 줄은 원자를 ID로 바꿔서 재채점한 것이 아니다. **존재하지 않는 부모 문자열이 실제 이력의 atom 문자열과 같은지** 분류한 관측이다. 반복 규칙 단계를 독립 graph나 독립 문제 수로 세지 않는다.

### 5.2 노드 표를 제공해도 생긴 실제 사례

`U01 shallow / t016_inventory_allocated`의 마지막 규칙이다.

```text
j96: C19 AND C02 AND C40 → C16

이미 생성된 노드와 입력 노드 표:
v087_node_0001 → C19
v087_node_0002 → C02
v087_node_0003 → C40
```

실제 원응답:

```json
{"node":{"atom":"C16","id":"v087_node_0004","parents":["C19","C02","C40"],"rule":"j96"}}
```

현재 노드 ID는 지정한 `v087_node_0004`를 사용했다. 출력 원자와 규칙도 맞다. 그러나 parents에는 실제 node ID가 아니라 원자 이름이 들어갔다. **C19/C02/C40이라는 ID의 노드는 생성되지 않았다.** 올바른 id–atom 표가 입력에 있었는데도 발생했다.

### 5.3 초기 명명 방식과 맞물리는 관측

사후에 조건을 좁혀, **동일 unit이고 실제 facts 노드 배열까지 같으며 facts의 id와 atom이 같은 경우**만 비교했다.

- baseline 대 allocated_id: 일치하는 47조건에서 **47/47 → 0/47**.
- baseline 대 inventory_allocated: 일치하는 47조건에서 **47/47 → 0/47**.

두 47조건 집합은 서로 완전히 같지는 않으며 추가 독립 표본으로 합치지 않는다. 사전 주평가가 아닌 관측 하위집합 분석이다. 초기에는 원자와 ID가 같은 표기를 쓰다가, 중간 노드에는 도구가 다른 ID를 부여한 상황에서 원자 이름을 계속 참조하는 현상과 부합한다. 이 결과만으로 모델 내부 원인이나 이름 길이 단독 효과를 확정하지 않는다.

이번 처치는 ID 자동 할당뿐 아니라 `v087_node_...` 명명 방식·스키마 제약·추가 안내를 함께 바꿨다. **이번 계약이 종단을 악화시켰다는 판단과, ID 지원 일반이 언제나 나쁘다는 판단은 다르다.**

## 6. 규칙 진단이 높은데 종단은 왜 낮았는가

`allocated_id`는 고정 이력의 한 규칙에서 **130/140**이었지만 전체 graph에서는 **32/128**이다. 두 결과의 평가 조건이 다르다.

**진단 560요청의 선행 이력 중 `v087_node_...` ID가 포함된 경우는 0개**였다. v086 원응답을 고정했기 때문이다. 진단은 기존 ID를 가진 부모에서 새 ID의 노드 하나를 출력하게 하지만, 그 새 노드를 다음 규칙에서 다시 참조하게 하지는 않는다.

반면 실제 종단은 앞에서 할당한 ID가 다음 요청의 이력에 누적된다. 두 ID군의 첫 규칙은 **256/256 유효**했으며, 실패는 두 번째 규칙 이후에 발생했다. 즉 이번 국소 진단은 **새 이름을 만드는 순간**을 측정했지만, 그 이름이 바뀐 상태를 계속 유지하며 후속 부모를 연결하는 과정은 측정하지 않았다.

따라서 높은 단일 규칙 점수를 그대로 전체 실행의 성공 예측치로 사용하면 안 된다. 국소 진단이 무효인 것은 아니지만, **지원 처치가 바꾼 후속 입력 상태로까지 일반화할 근거가 없었다**는 점이 이번 실험에서 드러났다.

진단의 anchor 선정은 대상 응답이나 최종 성공을 읽지 않고 유효 prefix만 검사한 정책과 70개 모두 일치했다. 이 문제는 성공한 결과만 골라 진단했다는 문제가 아니라 **어떤 선행 이력을 시험했는가의 범위 문제**다.

## 7. 노드 표 단독은 무엇을 바꿨는가

국소 규칙 진단 총계는 134/140으로 같지만 실패 위치가 바뀌었다.

- U06 shallow의 마지막 o51 규칙은 기준에서 두 seed 모두 실패, 노드 표에서는 두 seed 모두 성공했다.
- 반대로 U03 shallow의 세 번째 규칙은 기준에서 두 seed 모두 성공, 노드 표에서 두 seed 모두 실패했다.
- U01 deep의 마지막 규칙과 U03 shallow의 네 번째 규칙 실패는 유지됐다.

즉 **2건을 고치면서 다른 2건을 잃었다.** 총계가 같다고 원응답도 전부 같았던 것은 아니다.

실제 종단에서는 U01 양방향이 6/8→4/8로 낮아지고, U03은 3/8→5/8, U06은 1/8→2/8, U08은 7/8→8/8로 높아졌다. 국소 U06 진단의 전부 성공이 전체 U06 종단의 전부 성공으로 이어진 것은 아니다.

## 9. 입력 동일성과 공유 선택

공통 비교·조회 256요청은 v086의 해당 요청과 바이트가 같았다. 응답 content까지 같은 것은 248건이었다. 후보 선택은 이번에도 128조건 전부 정확했다. 선택 응답 원문을 네 생성군이 그대로 공유한 것을 확인했다.

첫 facts 요청은 모든 군 쌍에서 **128/128 바이트 일치**한다. 다만 같은 요청에서도 실제 응답의 표현·노드 ID가 달라지는 사례가 있다. 예를 들어 baseline 대 allocated_id에서 facts content가 같은 것은 117쌍, 파싱한 노드 배열이 같은 것은 120쌍이다.

따라서 종단 차이는 동일 facts를 강제로 공유한 완전 동일 이력 대조가 아니라, 사전 배정한 지원 절차를 각자 실행한 결과다. 이미 고정 이력을 쓰는 규칙 진단과 구분한다. 동일 facts 하위집합에서도 대규모 ID군 실패가 확인됐으므로 전체 악화를 단지 첫 응답 변동만으로 설명하지는 않는다.

## 11. 연구상 결론과 다음 판단

이번 결과에 맞는 기술은 다음과 같다.

> 정확한 외부 수치에 대한 두 단계 선택을 공유한 기존 8개 구조의 생성 지원 2×2 비교에서, 전체 노드 대응표의 단독 효과는 양방향 D 종단 기준 +3.125%p에 그쳤다. 새 식별자 자동 할당 계약은 준수됐지만 후속 부모 참조 오류가 증가했고, 단독 지원은 −59.375%p, 결합 지원은 −56.25%p였다. 국소 진단의 과거 유효 이력에는 새 ID가 없었으므로, 국소 규칙 성공이 변경된 식별자 이력에서의 종단 성공으로 이어지지 않았다.

**기존 D 제어의 증거를 폐기할 결과가 아니라, 이번 생성 보강안의 실패다.** 같은 배치의 기준선은 선택 128/128, 양방향 실제 종단 49/64를 유지했다. 반대로 부정 결과를 단순한 점수 문제가 아니라 실제 원응답 연결 실패로 확인했으므로, 새 ID 군을 기본 생성기로 채택하면 안 된다.

다음 우선순위는 추가 필드를 더 넣는 것이 아니라 **노드 이름을 부여하는 방식과 후속 참조의 일관성을 통제한 진단**이다. 같은 의미의 유효 prefix에서 모든 ID와 내부 참조를 일관되게 재명명한 뒤, 짧은 중립 ID·현재 할당 ID 등의 사전 고정 조건에서 다음 규칙을 비교하는 방식이 적합하다. 이렇게 해야 명명 표현 변화와 ID 충돌 방지의 효과를 더 분리할 수 있다. 변환된 진단 입력은 새 실험 처치로 기록하고 기존 evidence의 오류를 고친 결과로 사용하지 않아야 한다.

현재 이름 형식·스키마·추가 지시·후속 이력 변화가 함께 바뀌었으므로 특정 hidden-state·attention·학습 원인을 밝혀냈다고 쓰지 않는다. 노드 표 단독의 작은 순증도 구조별 손실과 함께 보존한다. 이번 분석에서 v088 작성이나 새 모델 실행은 하지 않았다.
