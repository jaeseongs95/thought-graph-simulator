# v057~v063 분석보고서 복원본

> 상태: **복원본**
>
> 이 구간은 ChatGPT Library에서 각 버전별 독립 분석보고서가 모두 분리된 형태로 확인되지 않았다.
> 따라서 보존된 세션 인계서, 연구 복귀 결정서, 후속 검증 문서에 명시된 결과만 버전별로 재정리한다.
> 확인되지 않은 세부 분모나 원인을 새로 만들어 넣지 않았다.

## 1. 구간 전체의 의미

v057~v063은 전체 proof graph 생성 실패와 경로 선택 실패를 분리해 보기 위한 진단 분기였다.
핵심 흐름은 다음과 같다.

1. 전체 증명 생성과 마지막 규칙/경로 선택을 분리
2. 규칙 배열 순서가 선택에 미치는 영향 관찰
3. shallow/deep 지시 자체가 선택을 바꾸는지 검사
4. 마지막 규칙을 직접 지정했을 때 전체 graph를 구성할 수 있는지 검사
5. 새 호출을 중단하고 오프라인 진단 후 해당 국소 분기 종료

이 구간의 실패를 A/D/M 전체 실패로 확대하지 않았고,
반대로 규칙 선택 일부 성공을 종단 D 제어 성공으로 올리지 않았다.

## 2. v057 — graph 생성과 경로 선택 문제 분리

v057의 목적은
“전체 증명을 작성하는 것이 어려운가”와
“요구 경로를 고르는 단계부터 실패하는가”를 분리하는 것이었다.

현재 Library 보존 자료에서는 v057의 독립 분석보고서 원문과 전체 수치표를 확인하지 못했다.
따라서 이 복원본에서는 후속 v058~v063의 출발점인 **실험 분리 결정**만 보존한다.

## 3. v058 — graph 생성과 작은 선택 과제의 성능 분리

후속 보존 문서에서 확인되는 핵심 결과:

- Qwen 얕은 graph 생성: **20/20**
- Qwen 얕은 규칙 선택: **15/20**
- Qwen choice 원문: 얕은 규칙 15회, 깊은 규칙 5회
- Gemma choice: 20회 모두 깊은 규칙 `k17`
- Gemma graph는 JSON 형식은 맞았지만 논리 검증을 통과하지 못한 사례가 확인됨

따라서 작은 선택 과제의 성능과 전체 graph 구성 성능은 같지 않았다.
Qwen의 20/20 graph 구성 성공을 선택적 D 제어 성공으로 확대하지 않는다.

## 4. v059~v060 — 규칙 배열과 선택 행동

보존 인계서의 결론:

- 규칙 배열 순서에 따라 선택이 변했다.
- v059 단계에서는
  - “목록의 두 번째 항목을 고른다”
  - “처음으로 goal을 도출하는 규칙을 고른다”
  두 설명이 같은 예측을 내어 구분되지 않았다.
- v060에서 두 설명이 서로 다른 답을 예측하도록 배열을 바꿨고,
  관측 선택은 **첫 goal 도출 규칙** 쪽과 일치했다.

이것은 외부에서 관찰한 선택 패턴이다.
모델 내부 알고리즘이나 메커니즘을 밝혀냈다고 해석하지 않는다.

## 5. v061 — 깊이 지시만 바꾼 선택 검사

규칙 순서를 고정하고 shallow/deep 지시만 바꾼 결과:

- **40/40 모두 같은 규칙 `k03` 선택**
- shallow 조건은 맞고 deep 조건은 실패
- 깊이 지시 자체가 선택을 바꾸지 못했다

따라서 이 조건에서는 “D 지시를 바꾸면 경로 선택도 달라진다”는 효과가 관측되지 않았다.

## 6. v062 — 마지막 규칙 지정 후 전체 증명 구성

확인된 결과:

- 지정한 마지막 규칙 이름: **39/40**
- 전체 증명 성공: **0/40**

즉 외부 지시를 전부 무시한 것은 아니다.
규칙 이름은 거의 맞췄지만 그 규칙을 포함한 유효한 전체 proof graph 구성으로 이어지지 않았다.

규칙 이름을 맞힌 성과와 전체 증명 성공을 합산하지 않는다.

## 7. v063 — 새 호출 없이 오프라인 실패 진단

v063은 새 LLM 실험이 아니라 오프라인 진단 단계였다.

확인된 판단:

- 같은 K01/Gemma 문구·규칙 위치 변형을 계속하는 분기를 종료
- 연구 전체 종료가 아니라 **국소 진단 분기 종료**
- 짧은 조건에서 확인된 16/20 오류가 최종 지지 연결 밖에 있었다는 진단은
  기존 실패를 성공으로 재채점한 것이 아님

이후에는 실제 유효 graph 생성 이력이 있는 Qwen에서
원래 연구 질문인 직접 D 조작 실험으로 복귀했고, v064로 이어졌다.
