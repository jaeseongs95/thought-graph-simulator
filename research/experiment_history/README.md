# Experiment History

이 디렉터리는 Thought-Graph / A-D-M 연구의 로컬 LLM 실험 결과와 분석 이력을 보존한다.

단순한 과거 산출물 보관용 `archive`가 아니라, 이후 실험 설계와 해석에서 계속 참조하는
**연구 의사결정·실패 분해·검증 근거의 누적 기록**이다.

## 구간별 의미

### `early_local_llm/`

최초 로컬 LLM 실험 계보다.

- v0.1: 통합 출력 계약과 node reference 문제
- v0.2: 구성요소별 진단 도입, D/M 실패 분리 시작
- v0.3: 실패를 끝까지 수집하는 구조로 전환, 모델/모드 confound 확인
- v0.4.0: Instruct 기준선에서 premise ↔ parent binding 오류 확인

### `v041-v071/`

v0.4.0에서 확인된 실패를 더 작은 원인 단위로 분해한 시기다.
forensic/causal probe에서 시작해 D의 선택, 생성, reference, binding 문제를 순차적으로 분리했다.

`v050`, `v057~v063`은 독립 분석보고서 원본이 현재 보존 자료에서 확인되지 않아
후속 인계·대화·검증 기록을 근거로 복원한 문서이며, 파일명에 `복원본`을 명시했다.

### `v072-v076/`

별도 분석보고서보다 다음 revision의 연구 계획장부에 직전 실험의 실제 결과가
동결 기록되는 방식으로 관리된 구간이다. 원 장부를 그대로 보존한다.

### `v077-v087/`

버전별 결과 분석보고서가 독립 문서로 체계화된 구간이다.

## 원본과 복원본

- `원본`: 당시 저장된 분석보고서 또는 forensic 패키지에서 직접 추출한 문서
- `복원본`: 독립 보고서 원본은 확인되지 않았지만, 보존된 대화·인계·후속 검증 기록에서
  확인되는 수치와 판단만 재구성한 문서

복원본은 새 실험을 수행하거나 과거 실패를 사후 성공으로 재채점한 결과가 아니다.

## 관리 원칙

1. 기존 결과의 실패를 삭제하거나 덮어쓰지 않는다.
2. 원본과 복원본을 구분한다.
3. 코드 테스트, 합성 검증, 실제 모델 추론을 같은 증거로 합산하지 않는다.
4. 동일 응답의 재검산을 새로운 실험 표본으로 세지 않는다.
5. 후속 실험이 이전 결과를 수정할 경우 무엇이 바뀌었는지 명시한다.
6. 새로운 실험 분석보고서는 해당 버전 구간에 추가하고, 필요하면 구간 README를 갱신한다.
