# LLM 실험 작업공간

v047 이후의 실행 패키지와 자료를 한곳에 둔다. 각 실행 패키지는 이 디렉터리를 공통 루트로 사용하므로 기존 상대경로를 바꾸지 않고도 동결 계획과 결과를 찾을 수 있다.

```text
experiments/
├─ experiments_vNNN/        실행 전에 동결한 계획
├─ results_llm/             원문, 감사 결과, capture, evidence ZIP
└─ vNNN_<주제>_probe/       구현, 시험, 실행 스크립트, 검증 자료
```

실험을 실행할 때는 해당 버전 디렉터리로 이동해 그 안의 `README.md`와 `windows/` 스크립트를 따른다. 예를 들어 v054 실행 패키지는 `experiments/v054_order_probe/`에 있다.

과거 패키지와 결과는 당시 상태를 재현하기 위한 자료다. 새 실험은 기존 폴더를 수정하거나 덮어쓰지 않고 새로운 버전 디렉터리와 run 이름으로 추가한다.
