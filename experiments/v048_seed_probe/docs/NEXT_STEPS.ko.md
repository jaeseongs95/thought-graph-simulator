# v048 결과 이후의 연구 경로

## 먼저 볼 것

`data_integrity`, `data_complete`, `comparative_analysis_ready`가 모두 True인지 확인한다. 하나라도 아니라면 해당 실행을 완결된 모델 성능 비교로 사용하지 않는다. 미완료·실행 오류의 원문도 함께 보존한다.

그다음 전체 평균만 보지 말고 `summary.ko.md`의 seed별 표, 양성 입력, 파이프라인 중간값을 확인한다. 새 seed의 결과는 v047 발견 seed와 합산하지 않는다.

| 관측 | 현재 가능한 해석 | 다음 실험 |
|---|---|---|
| 대부분 또는 전부의 새 seed에서도 원식은 false만 출력하고 나머지 두 경로가 정확 | 발견 seed에만 국한되지 않는 표현/실행 구성의 행동 차이 | 목표 진리표를 고정한 표현 일반화 실험 |
| 원식도 모두 정확 | 등록한 새 seed에서는 과거 원식 실패가 유지되지 않음 | 설정 보존 여부와 seed별 차이 확인 후, 새 seed 결과를 보존하고 표현/원래 작업으로 이동 |
| 일부 seed에서만 교환식/연결식이 실패 | seed에 따른 실패 패턴이 존재 | 어느 입력·단계·표현에서 실패했는지 구분; 성공 seed만 선택하지 않음 |
| 연결식은 안정적이고 교환식은 불안정 | 등록한 조건에서 연결 구성의 정확도 이점이 관측됨 | 다양한 표현·문제와 실패 포함 비용을 비교 |
| 교환식과 연결식이 같은 정확도, 연결식 비용이 큼 | 이번 문제에서는 연결식의 정확도 이점이 추가로 관측되지 않음 | 중간값 관측·검증이라는 기능 차이와 최종값만 필요한 효율을 구분 |
| 연결식 최종값은 맞지만 NOT 중간값은 틀림 | 최종값 성공과 전체 경로 성공이 분리됨 | NOT의 오류와 실제 공급값에 대한 AND 오류를 구분 |

## 다음 표현 실험은 별도로 사전 동결한다

NOT의 위치, AND 피연산자 순서, 괄호 배치, 변수 이름을 한꺼번에 바꾸지 않는다. 관심 있는 요인을 분리한 동치 표현 집합을 정하고, 식 파서/진리표로 목표가 동일한지 먼저 검사한다. v048에서 얻은 결과를 보고 잘 되는 표현만 사후 선별해 평가 집합으로 사용하지 않는다.

seed 확장은 생성 조건의 확장이고 표현 확장은 입력 표기의 확장이다. 둘 다 문제 복잡도나 다른 추론 과제의 일반화를 대신하지 않는다. 현재 구성요소를 충분히 확인한 뒤에는 원래 전체 판단 작업에 연결한다.

## 본 가설로 돌아가는 기준

primitive와 연결 계약이 실제 모델 출력으로 작동하고, 대조군·오류 처리·자료 수집 기준이 안정적으로 정해지면 원래 전체 작업을 재실행한다. 그 상태에서 문제·목표를 고정하고 A/D/M 축을 따로 조작한다. 일반적인 단계 분해와 A/D/M 계약을 적용한 제어의 추가 효과를 구분할 대조군이 필요하다.

모델 크기별 비교를 모두 끝내야 A/D/M 조작을 시작할 수 있는 것은 아니다. 본 가설의 실행 가능성을 현재 모델에서 먼저 검증하고, 다른 소형 모델과 더 큰 모델은 외적 확장 및 비용·품질 비교로 배치한다. 모델 간 토큰 수를 동일 실제 연산량으로 대신하지 않는다.

## 보존할 자료

실행 원문 폴더, 별도 동결 계획, 사용한 소스와 가장 최근 감사 결과를 보존한다. `bundle` 명령의 ZIP은 v048 재감사에 필요한 파일을 함께 담는다. 과거 v047 원문도 별도로 계속 보존한다. 실패 실행이나 불리한 seed를 기록에서 삭제하지 않는다.
